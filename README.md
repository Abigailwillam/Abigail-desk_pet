# 阿比桌宠 · 通用桌宠框架

一个 **Electron 通用桌宠框架**，当前搭载角色「阿比盖尔」。透明无边框窗口、悬浮置顶、可拖拽，具备待机呼吸、重力下落、自主走动、点击互动、右键菜单与系统托盘。

> ## 🔁 想换成别的角色？
>
> **不用改任何代码。** 框架能力（窗口 / 拖拽 / 物理 / 番茄钟 / 喂食 / AI / 小点召回）
> 全部与角色无关；「桌宠是谁」收敛在 `pet-profile.json` 一个文件里。
>
> **换角色 = 改 `pet-profile.json` + 换 `assets/` 里的图 + 写一份台词 JSON。**
>
> 👉 详细步骤见 **[换角色指南.md](./换角色指南.md)**
>
> 改完跑一遍自检，全绿就说明换角色是安全的：
>
> ```bash
> npm run verify-all
> ```
>
> 其中 `npm run verify-swap` 会**临时换成一份假角色档案把整个应用重跑一遍**，
> 用来证明框架真的不依赖原角色 —— 这是最有说服力的一道保险。

## 启动

### 直接使用应用版（推荐）

`dist/AbbyDesktopPet-0.1.0-portable.exe` 是打包好的便携版，**双击即运行**，无需安装 Node.js，阿比会直接出现在桌面上。

### 开发调试

```bash
cd desktop-pet
npm install        # 首次安装 Electron
npm start          # 启动桌宠
npm start -- --dev # 启动并打开开发者工具
```

## 📦 分享给别人的电脑（分发）

最省事的方式是打成 **单文件便携版 exe**，发给对方后**双击即运行，对方电脑不用装 Node.js、不用装任何环境**：

```bash
npm run dist
# 产物：dist/AbbyDesktopPet-<版本号>-portable.exe
```

把生成的 `.exe` 通过 U 盘 / 微信 / 网盘发给对方，**双击就能跑**，阿比会直接出现在对方桌面上。

> **数据持久化已处理**：运行时产生的「设置 / 金币 / 待办」现在统一写在
> `C:\Users\<对方用户名>\AppData\Roaming\AbbyDesktopPet\` 下，
> 对方关掉再开不会丢（早期版本用临时目录路径会导致数据被清理，已修复）。

**备选方案**（不推荐给别人，适合自己备份）：

- 把整个 `desktop-pet` 目录（含 `node_modules`，约 950MB）拷给对方，对方双击 `启动桌宠-静默.vbs` 运行（对方也需有 Node.js，且首次会联网下载 Electron 二进制）。
- 只发源码（不含 `node_modules`）：对方 `npm install` 后 `npm start`（对方需有 Node.js + 能联网）。

**限制**：当前只打了 **Windows x64** 版。要支持 macOS / Linux 需在对应系统上分别 `npm run dist`（改 `package.json` 的 `win` 为 `mac` / `linux` 再打包）。

## 已实现的交互

| 操作 | 效果 |
|---|---|
| 单击（短按一下） | 开心弹跳 + 随机台词气泡（台词自带情绪，会切对应表情差分） |
| **双击**（快速点两下她） | 打开「与阿比聊聊天」窗（按 T 键等效） |
| 长按约 1 秒 | 确认为拖拽：切成被拎起的悬空姿态，可拖着她甩 |
| 拖拽中松手 | 重力下落到屏幕底部，落地时有一句反应台词 |
| 待机一段时间 | 每隔 18~42 秒自言自语一句（按羁绊等级选台词池） |
| 右键 | 菜单：大小 / 透明度 / 始终置顶 / **与阿比聊聊天** / AI 设置 / 隐藏 / 退出 |
| 托盘图标（左键单击） | 显示 / 隐藏；右键菜单同上 |
| **隐藏后：橙色小圆点** | 阿比藏起来后，桌面原地留一个**可拖动的橙色小点**；**单击小点**把她叫回来，位置会被记住（下次隐藏还在那儿） |

待机时角色会呼吸浮动，并每隔几秒随机走动一段；走到屏幕边缘会自动转身。

## AI 聊天（接入你自己的 API）

阿比可以接入任意**兼容 OpenAI Chat Completions 协议**的大模型服务，用户只需填自己的 API Key。

### 怎么配（三步）

1. 右键阿比 → **AI 设置（填 API Key）**（或点设置面板里的 **💬 与阿比聊聊天** 展开）
2. 填 **API Key**（必填）、**接口地址**、**模型名**（后两项有默认值，见下表）
3. 点 **保存并启用**，再点 **测试连接** 确认能通

配好后：**双击阿比**（连点两下她）或按 **T** 键，弹出「与阿比聊聊天」窗，回车发送。

### 聊天窗的版式

聊天窗（**与阿比聊聊天**）是**你说话的地方**——输入框是主体，字号放大到便于阅读。上方只做一句回显：

```
┌──────────────────────────────┐
│ 与阿比聊聊天        deepseek-chat  × │
├──────────────────────────────┤
│                          你说 │
│              ┌────────────────┐│
│              │ 今天过得怎么样？ ││
│              └────────────────┘│
│ 阿比说                          │
│ ┌────────────────┐             │
│ │ 御主今天也在努力呢～            │
│ └────────────────┘             │
├──────────────────────────────┤
│ ┌──────────────────┐ ┌──────┐ │
│ │ 对阿比说点什么…    │ │ 发送  │ │
│ └──────────────────┘ └──────┘ │
└──────────────────────────────┘
```

阿比的回复**同时**出现在两处：聊天窗里的回显气泡，以及桌面上阿比头顶的台词气泡（带表情差分）。
真正「演」这句话的是桌面上的气泡——关掉聊天窗也还在念。

另外：**已启用 AI 的话，每次启动桌宠阿比会主动打一句招呼**（内容即 `greetOnEnable`，同样走气泡 + 表情）。

### 人设与情绪

`systemPrompt` 里写的是**阿比本人的完整人设**（FGO 的阿比盖尔·威廉姆斯：称呼你为「御主」、
清教徒式的祈祷、塞勒姆、七个绳结与「门」、抱着的小熊玩偶），并要求模型：

- 只回 1~2 句、不超过 45 字，像桌面上随口接话；
- 不要 Markdown、不要旁白动作描写；
- **在回复末尾单独写一个情绪标记**，从 `[normal] [happy] [shy] [sad] [soft]` 里选一个。

主进程会把标记摘出来单独返回，正文只剩台词；标记则决定桌宠切哪张表情差分：

| AI 写的标记 | 桌宠表情 |
|---|---|
| `[normal]` / `[soft]` | 待机 |
| `[happy]` | 微笑 |
| `[shy]` | 害羞 |
| `[sad]` | 低头 |

改人设时**请保留末尾那条情绪标记要求**，否则 AI 回复将不再驱动表情。

### 常见服务商填法

| 服务 | 接口地址 | 模型名示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 本地 Ollama | `http://localhost:11434/v1` | `qwen2.5:7b` |

接口地址只填到域名也可以（会自动补 `/v1`），直接填完整的 `.../chat/completions` 也行。

### 配置存在哪

`ai-config.json`（与 `pet-config.json` 并列）。可以直接手改这个文件，也可以在设置面板里填——两种方式等价。面板保存时会保留你写在里面的 `_说明` 注释。

| 字段 | 说明 |
|---|---|
| `enabled` | 总开关 |
| `apiKey` | 你的 API Key（**只存在本机**，不会随日志或界面外泄） |
| `baseUrl` / `model` | 接口地址与模型名 |
| `temperature` / `maxTokens` | 生成参数（默认 0.9 / 220，短回复够用） |
| `timeoutMs` | 请求超时（默认 20 秒） |
| `systemPrompt` | 阿比的人设提示词，想改性格就改这里 |
| `historyRounds` | 携带几轮上下文（默认 6 轮，只在本次运行内保留，重启清空） |

### 实现要点

- **API 调用跑在主进程**（`src/ai-chat.js`），Key 不下发到渲染层——设置面板只能拿到掩码（如 `sk-••••cdef`），不回显明文。
- 用 Node 内置 `https`/`http` 实现，**零第三方依赖**。
- 模型回复会自动清洗（去 Markdown 星号、去引号、折行压成空格、超长截断），保证气泡里是干净的台词。
- 回复末尾的情绪标记由 `parseEmotion()` 摘出，正文才送进气泡；标记不合法（不在白名单）就当正文处理，不会误判。
- 出错分场景提示：401 会带服务端的原始错误信息，另有「网络错误」「请求超时」等中文提示。

改完 AI 相关代码可跑 `npm run verify-ai` 自检（36 项，不需要真实 Key，
含本地假服务端到端、情绪标记解析、人设提示词断言、错误分支）。

改完 AI 模块可跑 `npm run verify-ai` 自检（不需要真实 Key）：会验证配置读写、Key 掩码不泄露明文、
各服务商接口地址拼接、回复清洗，并起一个本地假服务做端到端请求 / 错误分支测试。

## 目录结构

```
desktop-pet/
├─ package.json          # electron 依赖与启动脚本
├─ pet-config.json       # 所有可调参数（尺寸、重力、速度、差分图、待机说话间隔）
├─ food-config.json      # 喂食系统配置（金币收益、内置食物与价格）
├─ ai-config.json        # AI 聊天配置（API Key / 接口地址 / 模型 / 人设提示词）
├─ assets/
│  ├─ idle.png           # 待机站姿（默认形态）
│  ├─ lifted.png         # 被拎起（拖拽时的姿态）
│  ├─ falling.png        # 下坠（松手坠落时的姿态）
│  ├─ abby.png           # 比心微笑
│  ├─ smile.png          # 表情差分：开心
│  ├─ shy.png            # 表情差分：害羞
│  ├─ sad.png            # 表情差分：低落
│  └─ tray.png           # 系统托盘小图标
├─ scripts/
│  ├─ verify-dialogs.js  # 台词池 / 情绪映射 / 素材齐全性自检
│  ├─ verify-ai.js       # AI 模块自检（配置 / 掩码 / 地址拼接 / 情绪标记 / 人设 / 端到端）
│  └─ verify-orb.js      # 橙色小点交互自检（单击召回 / 拖动不误判）
└─ src/
   ├─ main.js            # 主进程：窗口 / 托盘 / 菜单 / IPC
   ├─ ai-chat.js         # AI 聊天：OpenAI 兼容接口调用（Key 只留主进程）
   ├─ index.html         # 页面结构（角色 + 气泡）
   ├─ chat.html/js       # 聊天窗：用户输入为主，上方回显「你说 / 阿比说」
   ├─ orb.html/js        # 隐藏阿比后的橙色小点：单击召回，按住拖动
   ├─ style.css          # 状态动画（呼吸 / 走路 / 下落 / 弹跳 / 温柔上浮）
   ├─ dialogs.js         # 台词库 + 情绪标签（羁绊分级 / 时间段 / 特殊语音）
   └─ renderer.js        # 行为逻辑：物理、拖拽、走动、互动、表情调度
```

## 可调参数（pet-config.json）

| 字段 | 作用 |
|---|---|
| `size` | 窗口宽高，角色按高度自适应缩放 |
| `physics.gravity` | 下落加速度 |
| `physics.walkSpeed` | 走动速度 |
| `physics.maxFallSpeed` | 最大下落速度 |
| `timing.idleBeforeWalk` | 待机多久后开始走动（毫秒区间，随机取值） |
| `timing.walkDuration` | 单次走动持续时长（毫秒区间） |
| `timing.bubbleDuration` | 台词气泡显示时长 |
| `timing.holdToDragMs` | 长按多久才算进入拖拽状态（默认 1000 毫秒） |
| `timing.idleSpeak` | 待机自言自语间隔（毫秒区间，默认 `[18000, 42000]`） |
| `interaction.dragMoveThreshold` | 按下后移动超过多少像素直接判定为拖拽（默认 12 像素） |
| `sprites` | 差分图文件名映射（姿态图 + 表情图） |
| `dialogs` | 台词库缺失时的兜底文本（正常走 `src/dialogs.js`） |
| `win.disableHardwareAcceleration` | Windows 上透明窗口发黑时保持 true |
| `win.stopAtScreenBottom` | `true`=落到屏幕真正最底部（会压在任务栏上）；`false`=停在任务栏上方（不遮挡任务栏） |

## 状态差分图（表情姿态切换）

程序会按状态自动切换立绘。这里有两套并存的表情体系：

**① 姿态图 —— 由状态机驱动**（`pet-config.json` 的 `sprites` 里配置）：

| 状态 | 使用的图 | 触发时机 |
|---|---|---|
| `idle` | `idle.png` | 待机呼吸、走路（默认形态） |
| `dragged` | `lifted.png` | 被鼠标按住拖拽的瞬间（被拎起的悬空姿态） |
| `falling` | `falling.png` | 松手后下坠过程中（双手捂裙、闭眼紧张），落地即切回 |
| `happy` | `abby.png` | 单击互动时的比心形态（弹跳动画期间） |

**② 表情差分 —— 由台词情绪驱动**（`src/dialogs.js` 里每条台词自带 `e` 情绪字段）：

| 情绪标签 | 使用的图 | 适用台词 |
|---|---|---|
| `normal` | `idle.png` | 平静叙述、祈祷、日常 |
| `soft` | `idle.png` + 轻微上浮动画 | 温柔低语、安心的时刻 |
| `happy` | `smile.png` | 节日、被夸、御主来了等明亮台词 |
| `shy` | `shy.png` | 撒娇、粘人、被摸头、害羞 |
| `sad` | `sad.png` | 寂寞、塞勒姆回忆、低理智、特殊语音 |

说话时自动切到对应表情，说完（约 2.6 秒）恢复姿态图；被拖拽或下坠时姿态优先，不抢表情。

### 台词系统（`src/dialogs.js`）

台词按游戏语音语境分组，并按羁绊等级递进播放：

- **待机**：`idleInitial` → `idleBond1` ~ `idleBond5`（随羁绊提升换池子）
- **待机·日常**：`idleDaily` + `timeGreet`（按早/午/晚/深夜自动挑问候，另含雨天专用）
- **点击**：`clickDaily` / `clickLow`（低羁绊）/ `clickHigh`（高羁绊）
- **特殊低概率**：`special`（13 条「门后」氛围语音；深夜与连续快点时触发率提高）
- **系统事件**：`system`（打招呼 / 被拎起 / 落地 / 待机太久搭话等）

**羁绊系统**：每互动 8 次升一段（最高 5 段），存档在 localStorage，重启不丢。羁绊越高，点击时越容易挑到高羁绊台词，待机也会换到更亲昵的池子。

### 想再加表情差分

1. 把新透明底 PNG 放进 `assets/`（建议与现有素材同画布，见下方「素材规格」）；
2. 在 `pet-config.json` 的 `sprites` 里加一项，并在 `src/renderer.js` 的 `SPRITES` 与 `SPRITE_BY_EMOTION` 里登记；
3. 在 `src/dialogs.js` 里给需要用到该表情的台词打上对应情绪标签。

改完可跑 `node scripts/verify-dialogs.js` 自检台词池、情绪映射与素材文件是否齐全。

## 素材规格（重要）

`assets/` 下所有差分图**统一画布 986×1413**，站立类角色高约 1407px 且**脚底贴画布底边**，这样切换表情时角色不会缩小或飘起来。

生成新差分的完整流水线（脚本在 `generated-images/`）：

1. `_pet_expression_matting.py` —— 白底生成图 → 真透明（连通域抠图 + 水印清除）
2. `_pet_expression_align.py` —— 按角色实际高度归一化，对齐到统一画布与脚底站位

> 旧素材的原始裁剪框坐标由 `_pet_sprites_trim.py` 算出，新脚本会按画布比例自动映射复用。
